## 9. Data Flow

### 9.1 ביקורת גוגל (חיבור מלא)
```
GOOGLE (Business Profile) ──[סנכרון כל 30 דק']──► GoFive: ביקורות ──► מסך ביקורות / דשבורד / התראות
USER: תשובה ──► GoFive ──► GOOGLE API ──► התשובה מופיעה בגוגל ──► GoFive מעדכנת "נענתה"
```
- **Source of Truth:** גוגל. GoFive מחזיקה עותק.
- **מה מגיע מגוגל:** כותב, דירוג, טקסט, תאריך, תשובה קיימת.
- **מה נוצר ב-GoFive:** תגיות נושא (AI), סימון שנשלחה התראה, טיוטות.
- **מי רואה:** כל משתמשי העסק. משתמש מוגבל רואה רק את הסניף שלו.
- **שינוי בגוגל** (תשובה שנמחקה או ביקורת שנערכה): מתעדכן בסנכרון הבא. Needs Verification למחיקת ביקורת בגוגל (OQ-037).

### 9.2 ביקורת לפי קישור (SerpApi)
```
GOOGLE MAPS (ציבורי) ──► SerpApi ──[כל 6 שעות]──► GoFive: ביקורות (קריאה בלבד)
USER: "לענות בגוגל" ──► נפתח גוגל (מחוץ ל-GoFive)
```
התשובה שנכתבה בגוגל נקלטת ב-GoFive רק בסנכרון הבא.

### 9.3 נתוני פרופיל (חיבור מלא)
```
GOOGLE Performance API ──[יומי, 18 חודשים בפעם הראשונה]──► GoFive: צפיות, שיחות, הגעה, אתר, חיפושים
──► דשבורד (פניות מגוגל, כל הנתונים) / תובנות AI / דוח חודשי
```
גוגל מוסרת באיחור של כמה ימים. החיפושים מגיעים לפי חודש.

### 9.4 משוב מהסקר
```
CUSTOMER ──► GoFive (דירוג, תשובות, פרטים) ──► משוב מהסקר
                    ├─► Webhook של העסק (אם הוגדר)
                    ├─► Push + מייל (לא מרוצה, אם מופעל)
                    ├─► AI: תגיות נושא (רקע)
                    └─► מרוצה: קישור לגוגל ──► GOOGLE (הלקוח כותב שם, מחוץ ל-GoFive)
```
**Source of Truth:** GoFive. המשוב לא עובר לגוגל. ביקורת שהלקוח כתב בגוגל חוזרת ל-GoFive כביקורת גוגל רגילה, **בלי קישור** למשוב (OQ-038).

### 9.5 פעולות "מה לעשות"
```
בדיקת פרופיל + ביקורות + פוסטים + בדיקת אתר + בדיקות AI + סימונים ידניים ──► מצב לכל פעולה ──► ציון ──► דשבורד, שלב 2, פיילוט
AI: "על העסק" + פרופיל + ביקורות 5★ ──► טיוטה (נשמרת האחרונה לכל סוג)
```

### 9.6 תשלום (iCount)
```
OWNER ──► בקשת מסלול (GoFive) ──► עמוד iCount ──► תשלום ──► IPN ──► GoFive: התאמה ──► active
                                                                     └─► אין התאמה ──► GOFIVE ADMIN מפעיל ידנית
```
**Source of Truth לתשלום:** iCount (חשבוניות, הוראת קבע). **Source of Truth לגישה:** שדה המצב של העסק ב-GoFive.

### 9.7 נראות ב-AI / מפות / מתחרים
```
GoFive ──[שאלה / חיפוש / שם עסק]──► SerpApi / Claude / ChatGPT / Gemini / Perplexity ──► תשובה ──► GoFive: ניתוח ושמירה ──► עמודים, יעדים, התראות ירידה
```
כל בדיקה נשמרת עם תאריך, וההיסטוריה מאפשרת מגמה, "לפני חודש" והתראות.

## 12. Statuses

### 12.1 מצב העסק (Billing / Access)

| Status | משמעות | מה המשתמש רואה |
|---|---|---|
| `trial` | ניסיון, עם ימים שנותרו | פס "ניסיון: עוד N ימים". מכסות ניסיון (חוץ מפיילוט) |
| `active` | פעיל (שילם / הופעל ידנית / סוכנות / מנהל מערכת) | הכול |
| `paused` (reason: trial) | הניסיון נגמר | הסקרים סגורים. פס "בחרו מסלול" |
| `paused` (reason: stopped) | הושהה (מנהל מערכת / כשל תשלום / ביטול ב-Cardcom) | כנ"ל |
| `unpaid` (reason: new) | נרשם ולא שילם (בלי ניסיון) | רק "התוכנית שלי" |

```
הרשמה ──► trial ──(נגמר)──► paused ──(תשלום / הפעלה)──► active
   └──► unpaid ──(תשלום / הפעלה)──► active ──(השהיה / כשל)──► paused
                                     └──(ביטול Cardcom)──► active עד סוף התקופה ──► paused
```

### 12.2 סניף
`כבוי ⇄ פעיל`, `כבוי → ממתין לתשלום → פעיל` (FLOW-010).

### 12.3 קמפיין
`פעיל ⇄ לא פעיל` (ידני). עסק מושהה = הסקר סגור גם בקמפיין פעיל.

### 12.4 משוב (Response)
`נפתח (דירוג בלבד) → הושלם` · טיפול: `חדש → בטיפול → טופל / סגור ללא טיפול` · מעקב: `— → נשלח "האם טיפלנו" → כן / לא` · פרסום: `לא מפורסם ⇄ מפורסם`.

### 12.5 ביקורת גוגל
`מחכה לתשובה → נענתה` · התראה: `לא נשלחה → נשלחה` · תיוג: `ללא → מתויגת`.

### 12.6 הזמנה ללקוח (Invite)
`נוצרה → נשלחה (מייל / וואטסאפ / ידני) → נפתחה → הגיב` · `נשלחה → תזכורת`. API: `מתוזמנת → נשלחה`, או `דולגה` (כפילות).

### 12.7 הזמנה לצוות
`ממתינה → התקבלה / פגה (7 ימים) / בוטלה`.

### 12.8 בקשת מסלול ותשלום
בקשה: `אין → ממתינה (plan_request) → הופעלה (נמחקת)`. IPN: `received → activated / manual`. Cardcom: `pending → paid / failed`.

### 12.9 פעולה ב"מה לעשות"
`לביצוע → חלקית → בוצע` (אוטומטי), או `לביצוע ⇄ בוצע` (ידני). שבועית / חודשית: חוזרת ל"לביצוע" בתקופה הבאה.

### 12.10 בדיקות (פרופיל / מפות / AI / אתר / מתחרה)
`לא נבדק → רץ → הצליח / נכשל (עם סיבה)`.

### 12.11 2FA
`כבוי → בהגדרה (סוד נוצר) → מופעל (10 קודי גיבוי) → כבוי`.
