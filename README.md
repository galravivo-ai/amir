# GoFive (גו פייב)

<img src="public/brand/gofive-logo-email.png" width="180" alt="GoFive">

קדימה ל-5 כוכבים: מערכת ביקורות וחוויית לקוח לעסקים בישראל.

מערכת עצמאית (לא וורדפרס) לאיסוף משוב מלקוחות, טיפול בלקוחות לא מרוצים והגדלת הביקורות בגוגל.
הלקוח סורק QR או פותח קישור אישי, מדרג, עונה על שאלות קצרות שמותאמות לדירוג שלו, ומקבל את המסך המתאים.

## הזרימה

```
סריקת QR / קישור אישי (וואטסאפ, SMS, מייל)
        │
        ▼
   דירוג 1–5 ★
        │
   ┌────┴─────┐
 מרוצה       לא מרוצה (מתחת לסף שנקבע בקמפיין)
   │           │
שאלות קצרות    שאלות "מה לא עבד" + טופס פרטי קשר
+ אישור פרסום   │
   │           פנייה בלוח הבקרה + מייל מיידי + Webhook
כפתור גדול     ומעקב זמן טיפול (התראה אם לא טופלה בזמן)
לביקורת בגוגל  (קישורי הביקורת הציבוריים עדיין מוצגים, בקטן)
```

### למה לקוח לא מרוצה עדיין רואה קישור לגוגל?
גוגל אוסרת במפורש "Review gating", כלומר לשלוח לביקורת ציבורית רק לקוחות מרוצים.
עסק שנתפס בזה עלול לאבד ביקורות ואף לקבל השעיה של הפרופיל.
לכן המערכת **מציעה ללקוח הלא מרוצה קודם כל ערוץ פרטי**, ולא מסתירה ממנו את האפשרות לכתוב ביקורת פומבית.

## פיצ'רים

**איסוף משוב**
- קמפיינים: לכל סניף, עמדה או ערוץ יש קישור ו-QR משלו, סף "מרוצה", שאלות וטקסטים.
- בונה שאלות: בחירה אחת, בחירה מרובה, טקסט חופשי, NPS. כל שאלה לכולם, רק למרוצים או רק ללא מרוצים.
- QR כ-PNG/SVG ושלט להדפסה, כולל QR נפרד לכל מקור (שולחן, קופה, עובד).
- בקשות אישיות ללקוח: בוואטסאפ, SMS או **מייל אוטומטי**, עם **תזכורת אוטומטית** למי שלא ענה.
- עברית ואנגלית, RTL מלא, מותאם לנייד.

**טיפול בלקוחות לא מרוצים**
- כל לקוח לא מרוצה הוא פנייה עם סטטוס, הערות פנימיות וכפתורי וואטסאפ, חיוג ומייל.
- **מייל מיידי** להנהלה על כל לקוח לא מרוצה.
- **זמן טיפול (SLA)**: פנייה שלא טופלה בזמן שהוגדר מסומנת "באיחור" ונשלחת עליה תזכורת.
- מדידת זמן טיפול ממוצע.
- **ניסוח תשובה ללקוח עם AI**: טיוטה אישית שמתייחסת למה שהלקוח כתב. עורכים ושולחים בוואטסאפ או במייל.

**ניתוח**
- לוח בקרה: סריקות, דירוגים, המרה, ממוצע, NPS, קליקים לביקורת, פניות פתוחות ובאיחור, זמן טיפול, מגמה יומית, התפלגות, "מה הלקוחות אומרים", מקורות.
- **תובנות AI**: סיכום של מה עובד, מה צריך לתקן ומה לעשות השבוע, על בסיס המשובים.
- **דוח שבועי במייל** בכל יום ראשון בבוקר.
- ייצוא CSV (נפתח נכון באקסל בעברית).

**ווידג'ט המלצות לאתר העסק**
- לקוח מרוצה יכול לאשר פרסום של ההערה שלו (עם שם פרטי בלבד).
- העסק מאשר מה עולה (או מפעיל פרסום אוטומטי).
- שתי שורות קוד שמדביקים בכל אתר (וורדפרס, Wix וכו'), והגובה מתאים את עצמו.

**אוטומציה וחיבורים**
- **API לשליחה אוטומטית**: הקופה, מערכת התורים, החנות או Make / Zapier שולחים את פרטי הלקוח בסוף הביקור, ואנחנו שולחים לו בקשת דירוג (עם השהיה לבחירה, ובלי לשלוח שוב לאותו לקוח תוך 30 יום). מפתחות וניהול תחת "חיבורים".
- **סגירת מעגל**: כשפנייה מסומנת "טופל", הלקוח מקבל שאלה בלחיצה אחת "האם הטיפול עזר?". "לא" פותח את הפנייה מחדש ומתריע להנהלה. בלוח הבקרה: אחוז הלקוחות שהוחזרו.
- **תיוג אוטומטי ב-AI**: כל הערה מתויגת לפי נושא (שירות, זמן המתנה, מחיר...). אפשר לסנן לפי נושא, ובלוח הבקרה יש "נושאים חוזרים".
- **אפליקציה והתראות**: מתקינים את המערכת למסך הבית, ומקבלים התראה לטלפון על לקוח לא מרוצה, פנייה באיחור, או לקוח שהטיפול לא עזר לו.

**דירוג עובדים וסניפים**
- לכל עובד קישור ו-QR אישי: לקוח שסורק אותו נספר לעובד, בלי שאלות. אפשר גם לשאול בסקר "מי נתן לך שירות?".
- טבלת דירוג לעובדים ולסניפים לפי תקופה: ממוצע, אחוז מרוצים, כמה הגיעו לביקורת. מי שיש לו מעט דירוגים מתקרב לממוצע העסק, כך שדירוג 5 יחיד לא עוקף עובד עם עשרות דירוגים.
- סינון תגובות לפי עובד, העובד בייצוא ל-CSV, והעובד המוביל בדוח השבועי.

**שפות ותבניות**
- הסקר בעברית, אנגלית, ערבית ורוסית.
- תבניות לפי סוג עסק (מסעדה, מספרה, מרפאה, חנות, בעל מקצוע, מלון), עם שאלות מוכנות בכל השפות.
- צ'קליסט "צעדים ראשונים" לעסק חדש, שמתעדכן לבד לפי מה שכבר נעשה.

**סוכנויות ומיתוג לבן**
- סוכנות (משווק, יועץ, משרד פרסום) מנהלת את כל העסקים שלה ממסך אחד, פותחת לקוחות חדשים ונכנסת לכל אחד בלחיצה.
- השם, הצבע והלוגו של הסוכנות מחליפים את המיתוג שלנו אצל הלקוחות שלה, ואפשר גם דומיין משלה (תעודת HTTPS יוצאת לבד, ראו DEPLOY.md).
- מנהל המערכת יוצר סוכנויות, מוסיף אנשי צוות, קובע מכסת לקוחות ותוכנית ברירת מחדל.

**צוות וריבוי עסקים**
- כמה עסקים בחשבון אחד, כל אחד עם מיתוג, צוות ונתונים נפרדים.
- הזמנת משתמשים במייל עם תפקידים:

| תפקיד | מה מותר |
|---|---|
| בעלים | הכול, כולל הגדרות העסק, צוות ומחיקה |
| מנהל | קמפיינים, טיפול בפניות, שליחת בקשות, AI, אישור המלצות |
| צפייה בלבד | לוח בקרה ותגובות, בלי לשנות דבר |

**חשבון**: שכחתי סיסמה (קישור במייל), שינוי סיסמה (מנתק את שאר המכשירים), עדכון פרטים, ו**אימות דו-שלבי** עם אפליקציית אימות (Google Authenticator וכדומה) וקודי גיבוי.

**תוכניות וניהול מערכת**
- שלושה מסלולים, מחירים לחודש כולל מע״מ: **בסיסי ₪99** (סניף אחד), **מקצועי ₪159** (עד 3 סניפים), **עסקי ₪399** (עד 10 סניפים). כל הפיצ'רים כלולים בכל המסלולים, ההבדל הוא רק במספר הסניפים. בתשלום שנתי משלמים על 10 חודשים ומקבלים 12. הכול מוגדר במקום אחד: `src/plans.js`.
- סוכנויות ורשתות עם יותר מ-10 סניפים מקבלות הצעת מחיר אישית: טופס בדף הנחיתה (או כפתור במסך "התוכנית שלי") שולח מייל למנהלי המערכת, והפניות מרוכזות בניהול המערכת. לרשת מפעילים את מסלול "רשת" (סניפים ללא הגבלה), שלא מופיע במחירון.
- עסק חדש מקבל 7 ימי ניסיון במסלול מקצועי (3 סניפים), בלי כרטיס אשראי. יום לפני הסוף ובסוף נשלח מייל. אם לא נבחר מסלול, הסקרים, ה-API והווידג'ט מושהים והנתונים נשמרים.
- תשלום אונליין עוד לא מחובר: בעל העסק בוחר מסלול במסך "התוכנית שלי", מנהל המערכת מקבל מייל, ואחרי שהתשלום הוסדר לוחץ "הפעלה" בניהול המערכת. משם אפשר גם להאריך ניסיון או להשהות חשבון.
- פאנל ניהול מערכת (`/superadmin`): כל העסקים, המסלול והסטטוס שלהם, בקשות למסלול, משתמשים, ויומן כל המיילים שיצאו.
- החשבון הראשון שנרשם הוא מנהל המערכת.

**אתר ודפים משפטיים**
- דף נחיתה שיווקי בכתובת הראשית (מי שמחובר עובר ישר ללוח הבקרה), עם טבלת מחירים שנבנית מ-`src/plans.js`.
- מדיניות פרטיות (`/privacy`) ותנאי שימוש (`/terms`). ההרשמה מחייבת לאשר אותם, ובתחתית כל סקר יש קישור למדיניות.
- בעלי העסק יכולים למחוק תגובה עם כל פרטי הלקוח, למשל כשלקוח מבקש למחוק את המידע עליו.
- **חשוב:** הטקסטים המשפטיים הם טיוטה טובה להתחלה, לא ייעוץ משפטי. כדאי שעורך דין יעבור עליהם לפני שמתחילים למכור.

**לוגו**: העלאת קובץ (PNG, JPG, WebP, GIF עד 1MB) או קישור לתמונה. הקובץ נבדק לפי התוכן שלו, ו-SVG נחסם כי הוא יכול להכיל קוד.

**אבטחה**: סיסמאות scrypt, הגנת CSRF, הרשאות לפי תפקיד, הפרדה מלאה בין עסקים, הגבלת קצב, חסימת ניחוש סיסמאות, CSP, קישורי איפוס והזמנה חד-פעמיים שנשמרים מוצפנים (hash), הגנה מהזרקת נוסחאות ל-CSV.

## הרצה

דרוש Node.js בגרסה 22.5 ומעלה (משתמש ב-SQLite המובנה, בלי מסד נתונים חיצוני).

```bash
npm install
cp .env.example .env   # ולמלא את מה שצריך
npm run seed           # אופציונלי: חשבון דמו עם נתונים, demo@example.com / demo12345
npm start              # http://localhost:3000
npm test
```

### העלאה לאוויר

מדריך מלא צעד אחר צעד ב-**[DEPLOY.md](DEPLOY.md)**: Railway (הכי קל) או שרת משלכם עם Docker ו-HTTPS אוטומטי.

### גיבוי

השרת מגבה את עצמו אוטומטית פעם ביום (14 אחרונים ב-`data/backups`). גיבוי ידני בכל רגע:

```bash
npm run backup
```

אפשר להריץ בזמן שהשרת עובד. כדאי להעתיק גיבויים גם למקום אחר מדי פעם.

| `TRUST_PROXY` | ריק | `1` כשהשרת רץ מאחורי Nginx / Cloudflare |

| `BACKUP_DIR` / `BACKUP_KEEP` | `data/backups` / `14` | תיקיית הגיבויים וכמה לשמור |

### משימות רקע
השרת מריץ כל 5 דקות: שליחת בקשות שתוזמנו דרך ה-API, תיוג הערות ב-AI, תזכורות ללקוחות שלא דירגו, התראות על פניות באיחור, דוח שבועי (ראשון, 08:00 שעון ישראל) וגיבוי יומי.
כל משימה רושמת מה נשלח, כך שאין כפילויות גם אחרי הפעלה מחדש.

## בהמשך

- חיבור ל-Google Business Profile API: משיכת הביקורות מגוגל ותשובה אליהן מתוך המערכת
- WhatsApp Business API / SMS: שליחה אוטומטית של בקשות ותזכורות
- תשלום אונליין על התוכניות
- דירוג עובדים וסניפים

## API

```bash
curl -X POST https://your-site/api/v1/invites \
  -H "Authorization: Bearer rk_..." -H "Content-Type: application/json" \
  -d '{"campaign": "main-branch", "name": "דנה", "email": "dana@example.com", "phone": "0501234567", "delay_minutes": 120}'
```

שדות: `campaign` (slug או מספר; ברירת מחדל: הקמפיין הפעיל הראשון), `name`, `phone`, `email` (חובה אחד מהם), `delay_minutes` (עד 10080), `external_id`, `dedup_days` (ברירת מחדל 30).
תשובה: `status` = `sent` / `scheduled` / `created` / `skipped`, ו-`invite.link` לשליחה ב-SMS. בדיקה: `GET /api/v1/ping`, רשימת קמפיינים: `GET /api/v1/campaigns`.
